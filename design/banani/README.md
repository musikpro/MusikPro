# Banani design workspace

La connexion MCP Banani est **Claude Code uniquement** et doit utiliser le scope local Claude Code (`~/.claude.json` pour ce projet). Aucun token Banani ne doit être stocké dans le dépôt.

Après connexion réussie, utilise dans **Claude Code** :

```text
/import-banani
```

Les fichiers de ce dossier contiennent uniquement des snapshots/normalisations sans secret que les autres agents peuvent ensuite lire.
